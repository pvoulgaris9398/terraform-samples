## Resources

- Prefer conventions listed [here](https://learn.microsoft.com/en-us/azure/cloud-adoption-framework/ready/azure-best-practices/resource-naming)
- Use a hyphen when applicable
- Append a unique hashed string that is the id of the resource-group that resource is contained in
- Consider the details listed [here](https://learn.microsoft.com/en-us/azure/azure-resource-manager/management/resource-name-rules)
- Consider rules listed [here](https://learn.microsoft.com/en-us/azure/cloud-adoption-framework/ready/azure-best-practices/resource-abbreviations)
- And [here](https://learn.microsoft.com/en-us/community/content/azure-resources-naming-convention-and-tagging)
